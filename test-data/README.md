# Test Data

This directory contains synthetic, non-redeemable data for local QA and automated acceptance tests.

- `release5_acceptance_cards.csv` covers the Release 5 credential profiles: claim code, number plus PIN/access code, barcode, network prepaid, and custom issuer fields.
- Values are intentionally fake and must not be treated as real gift-card credentials.
- Do not add real card numbers, PINs, claim codes, security codes, billing addresses, or personally identifying data to this directory.
